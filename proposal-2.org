* TODO Remove the =mkHome= module option
:PROPERTIES:
:STRENGTH: Strong
:END:

Files: [[file:modules/flake/home.nix][flake/home.nix]], [[file:modules/machines/][machines/]].

Problem: =mkHome= is a read-only option used only by the three machine files.
That makes a plain constructor look like shared Home Manager configuration.

Change: define the constructor as a local function in =home.nix= and expose
finished =flake.homeConfigurations= from the machine modules through one small
shared helper, or inline the seven constructor lines if that is clearer.

Benefit: removes one option declaration and makes the flake-construction
boundary easier to follow.

Preserve: package imports, overlay merging, module order, user names, systems,
and home directories. Do not replace explicit machine outputs with a registry.

Implementation sketch:

#+begin_src nix
# flake assembly layer
mkHome = { system, user, homeDirectory, modules }:
  inputs.home-manager.lib.homeManagerConfiguration {
    pkgs = import inputs.nixpkgs { inherit system; };
    modules = [{ home.username = user; home.homeDirectory = homeDirectory; }]
      ++ modules;
  };
#+end_src

Machine files call the shared constructor without declaring a Home Manager
=mkOption=.

New code location: [[file:modules/flake/home.nix][modules/flake/home.nix]]
for the flake-level constructor; machine call sites remain in
[[file:modules/machines/][modules/machines/]].

LOC estimate: =home.nix= 43 -> 37 (-6); machine files 25 -> 25 (+0);
combined 68 -> 62 (-6). Estimate excludes this proposal document.

* TODO Consolidate the three machine declarations around shared host data

* TODO Move =CK_OS= into machine modules
:PROPERTIES:
:STRENGTH: Worth exploring
:END:

Files: [[file/modules/platform/linux.nix][linux.nix]],
[[file/modules/platform/darwin.nix][darwin.nix]], machine modules.

Problem: =CK_OS= is host identity, while the platform modules also own package
and genericLinux behavior. The value is duplicated conceptually with each
machine's system declaration.

Change: set =home.sessionVariables.CK_OS= in each machine module and remove the
two one-entry platform attribute sets.

Benefit: removes a small indirection and makes the host value visible beside
the selected system.

Preserve: exact values =linux= and =osx=. Keep package policy in platform
modules unless those modules are also removed.

Implementation sketch:

#+begin_src nix
# modules/machines/flunder.nix
flake.homeConfigurations."gizmo@flunder" = config.mkHome {
  # existing fields...
  modules = [ common linux nixgl-intel ];
  # merged into the selected Home Manager config
};
# common/platform-independent equivalent:
home.sessionVariables.CK_OS = "linux";
#+end_src

In practice, place the session variable in each machine's selected module
attrs, then delete only the platform session-variable blocks.

New code location: the existing files under
[[file:modules/machines/][modules/machines/]]; no new file.

LOC estimate: platform files 33 -> 29 (-4); machine files 25 -> 27 (+2);
combined 58 -> 56 (-2).

* TODO Replace the dynamic own-app package map with a direct package list
:PROPERTIES:
:STRENGTH: Worth exploring
:END:

File: [[modules/features/own-apps.nix][own-apps.nix]].

Problem: the five package names are hidden behind dynamic attribute lookup:
=inputs.${app}.packages.${pkgs.stdenv.hostPlatform.system}.default=.

Change: use five direct package references, or a short local package list with
the same explicit references.

Benefit: readers can see each dependency immediately and Nix errors identify
the failing input without tracing a string list.

Preserve: default package selection and host-platform resolution. Keep the map
if more applications are added frequently and the list would otherwise repeat
the same expression.

Implementation sketch:

#+begin_src nix
system = pkgs.stdenv.hostPlatform.system;
home.packages = [
  inputs.dime.packages.${system}.default
  inputs.donies.packages.${system}.default
  inputs.sesame.packages.${system}.default
  inputs.spotify-dl.packages.${system}.default
  inputs.worker.packages.${system}.default
];
#+end_src

The exact input names stay visible; only the string-driven lookup disappears.

New code location: existing
[[file:modules/features/own-apps.nix][modules/features/own-apps.nix]]; no new
file.

LOC estimate: =own-apps.nix= 11 -> 13 (+2). LOC rises slightly; payoff is
clearer dependency ownership and better evaluation errors, not line reduction.
