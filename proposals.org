#+TITLE: Nix module cleanup proposals

Review of the current working tree, including uncommitted agent configuration.
Proposals are ranked; some overlap. Completed items are marked DONE.

Keep the existing dendritic design: import-tree discovers flake-parts modules,
named Home Manager modules define features, and three explicit machine modules
compose them. No new module framework, machine registry, or blanket enable flags.

Start with agent target ownership, then remove unused scaffolding and move
overlay contributions beside their consumers.

* DONE Let each agent module own its skills target
:PROPERTIES:
:STRENGTH: Strong
:END:

Files: [[file:modules/agent-skills.nix][agent-skills.nix]], [[file:modules/claude.nix][claude.nix]], [[file:modules/copilot.nix][copilot.nix]], [[file:modules/common.nix][common.nix]].

Problem: agent packages live in their own modules, but their skills targets live
in the shared skills module. Agent-specific knowledge crosses that seam.

Change: move =targets.claude= and =targets.copilot= declarations into their
respective agent modules. Keep shared sources, skill selection, the upstream
module import, and =targets.agents= in =agent-skills.nix=.

Before: shared skills module owns every agent's target.
After: each agent module owns its package and target.

Benefit: deeper agent modules and better locality, using existing module merging
without new files or options.

Preserve: all three destinations, link mode, and selected skills. Keep the shared
skills module selected whenever these target declarations are used.

:STRENGTH: Worth exploring

Problem: selecting =cli-tools= also installs Firefox, Chrome, Slack, and Zeal.
The module name does not describe its actual interface.
